3. 閱讀 [AGENTS.md](../AGENTS.md) — 了解開發規則

2. 閱讀 [extensions/auto-annotate.ts](../extensions/auto-annotate.ts) — 看具體實作

### 要修改依賴關係

### 要發佈新版本
