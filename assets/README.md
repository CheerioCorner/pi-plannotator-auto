# Assets

本資料夾存放 gallery 用的媒體檔案。

## 需要的檔案

### screenshot.png
- **用途：** pi.dev/packages gallery 的預覽圖
- **建議尺寸：** 1200x800 或 1600x900
- **格式：** PNG
- **內容：** Extension 的 UI 截圖或功能展示圖

### demo.mp4
- **用途：** pi.dev/packages gallery 的示範影片
- **格式：** MP4
- **長度：** 建議 30-60 秒
- **內容：** 展示 open_annotate tool 的使用流程

## 上傳方式

1. 將檔案放入本資料夾
2. Commit 並 push 到 GitHub
3. 確認 package.json 中的 URL 指向正確的檔案路徑

## URL 格式

```
https://raw.githubusercontent.com/CheerioCorner/pi-plannotator-auto/main/assets/screenshot.png
https://raw.githubusercontent.com/CheerioCorner/pi-plannotator-auto/main/assets/demo.mp4
```
